# Design history

These are the working notes from planning and building the original pumpkin, kept for anyone curious about why it ended up the way it did. They're written in order and are **superseded by the main README and the build guide**: several designs here were tried and dropped, including a backlit printed logo, a cut-through white T with LEDs in a light box, and an inner groove around the T's square.

| File | Covers |
|---|---|
| `01_Research_Notes.md` | The Slack-o-lantern, the source tutorials, and hardware research |
| `02_Build_Plan.md` | Options considered and the adversarial review of the plan |
| `03_Parts_List.md`, `07_Order_List.md` | Bills of materials and prices at the time |
| `04_Wiring.md`, `05_Firmware_Spec.md` | Wiring detail and the firmware specification |
| `06_Logo_and_Sound_Assets.md` | Logo versions and how the sound file was prepared |
| `08_Build_Checklist.md` | The original (backlit-logo) checklist |
| `09_EL_Wire_Design.md`, `10_Build_Changes.md` | The switch to EL wire and every change made during the build |
